# V5 Clean benchmark 阶段汇总

生成日期：2026-07-30

范围：Clean First-Born 图像、电子计数、独立仪器噪声、衍射盘检测、ACOM 与 `[001]` 专项研究。

未运行：multislice、任何 dynamical 模拟。

## 1. 已冻结的数据设计

### Headline 数据

- 2048 个经过晶体对称性和 Friedel 等价规范化的取向；
- 2048 张 `512 × 512`、float32、归一化的 coherent First-Born 期望衍射图；
- 与图像对应的 oracle 峰及逐反射 trace；
- 9 档独立电子剂量：
  `10², 3×10², 10³, 3×10³, 10⁴, 3×10⁴, 10⁵, 3×10⁵, 10⁶ e⁻`；
- 每档剂量 5 个确定性 Poisson 重复；
- 每档剂量均有不含随机噪声的剂量缩放图；
- 6 档独立噪声条件：
  `noiseless`、`poisson_only`、EMPAD-G2 的 1/4/16/64 帧等效读出噪声。

### 独立 `[001]` 研究数据

这 512 个样本不计入 2048 个 headline 样本：

| 分组 | 样本数 |
|---|---:|
| 精确 `[001]` | 32 |
| 近 `[001]`，倾角 0.125–2° | 320 |
| 过渡区，倾角 3–6° | 96 |
| `[100]` 对照 | 32 |
| `[110]` 对照 | 32 |

它具有与 headline 相同的期望图、九档无噪声剂量图、九档 × 5 次
Poisson 计数图、六档噪声参数与确定性种子、oracle 峰和逐反射 trace。

## 2. 固定物理和坐标参数

- 反射截止：`kmax = 1.5 Å⁻¹`，未改动；
- 图像倒空间视场：`qmax = 1.6 Å⁻¹`，仅用于容纳边缘有限尺寸衍射盘；
- `[001]` trace 的最大保留峰半径：`1.497136 Å⁻¹`；
- `[001]` trace 中半径大于 `1.5 Å⁻¹` 的保留峰数：0；
- 倒易基矢矩阵不含 `2π`，单位为 `Å⁻¹`；
- 图像模型：coherent First-Born kinematical CBED；
- 仪器噪声参考：EMPAD-G2，300 keV，DOI
  `10.1017/S1431927621013701`；
- 单帧等效读出噪声：
  `0.0086667 primary e⁻ RMS/pixel`；
- 多帧固定总剂量后求和，读出噪声按 `sqrt(frame_count)` 增长；
- 剂量和读出噪声是两个独立变量，同一 sample/dose/repeat 在不同读出
  噪声档复用同一 Poisson 图，只改变确定性读出噪声。

## 3. 实际执行情况

### First-Born 生成

- 2048 个 headline 样本：993.889 秒；
- 512 个 `[001]` 样本：130.481 秒；
- headline 共检查 1,339,284 个候选反射，阈值前合并为
  1,220,189 个盘，最终保留 276,661 个峰；
- 所有正式 HDF5 均可打开、样本数正确，没有残留 `.partial` 文件。

64 个样本的 CPU/CUDA 实测表明，CUDA 总时间仅快约 7.5%，GPU SM
利用率采样接近 0%，主要开销仍在 CPU 端 oracle 与 trace 后处理。因此正式
First-Born 生成采用 8 线程 CPU，没有为形式上的 GPU 使用而占用共享 GPU。
CPU/CUDA 图像像素 RMSE 为 `1.649×10⁻⁹`，8405 个匹配峰的 q-RMSE
为 `1.79×10⁻⁷ Å⁻¹`，HKL 一致率为 100%。

### Headline 无噪声期望图检峰

以下均为全部 2048 个样本的实际结果，三种方法调用失败数均为 0：

| 方法 | Precision | Recall | 位置 RMSE (pixel) | P95 (pixel) |
|---|---:|---:|---:|---:|
| AutoDisk | 0.9745 | 0.8745 | 0.1561 | 0.2396 |
| py4DSTEM `find_Bragg_disks` | 0.9825 | 0.8677 | 0.1647 | 0.3589 |
| DoG-RGM | 0.9860 | 0.8593 | 0.1504 | 0.2259 |

漏检主要集中在弱峰和相互拥挤的盘。所有方法均未触及 256 峰上限。
这些误差保留为 benchmark 结果，不通过调参把检测器强行变成 oracle。

## 4. 电子量增加是否有效

有效。以下是 8 个固定 smoke 样本、Poisson-only、repeat 0 的统一评价。
表中数值为 recall：

| 电子剂量 | AutoDisk | py4DSTEM | DoG-RGM |
|---:|---:|---:|---:|
| 100 | 0.0031 | 0.0084 | 0.0021 |
| 300 | 0.0136 | 0.0178 | 0.0147 |
| 1,000 | 0.0314 | 0.0387 | 0.0293 |
| 3,000 | 0.0628 | 0.0723 | 0.0482 |
| 10,000 | 0.1037 | 0.1298 | 0.0911 |
| 30,000 | 0.1696 | 0.2136 | 0.1560 |
| 100,000 | 0.2827 | 0.3330 | 0.2366 |
| 300,000 | 0.4387 | 0.5225 | 0.3267 |
| 1,000,000 | 0.6063 | 0.7099 | 0.5162 |

三种方法的 recall 都随电子量总体显著提高。无噪声剂量图只做线性缩放，
九档剂量的检峰输出保持一致，说明上述变化确实来自有限电子计数，而不是
把剂量与另一种图像处理混在一起。

## 5. 独立读出噪声扫描

固定剂量 `10⁴ e⁻`、固定 Poisson repeat 0，读出噪声从 EMPAD-G2
1 帧增加到 64 帧。以下为 8 个 smoke 样本的 recall：

| 噪声等级 | AutoDisk | py4DSTEM | DoG-RGM |
|---|---:|---:|---:|
| 1 frame | 0.1099 | 0.1298 | 0.0702 |
| 4 frames | 0.1026 | 0.1351 | 0.0702 |
| 16 frames | 0.1016 | 0.1225 | 0.0691 |
| 64 frames | 0.0932 | 0.1298 | 0.0607 |

此小样本结果有随机波动，但总体显示读出噪声增加不会带来系统性提升，
并会产生大量假阳性。这里不把方法错误当成 benchmark 构造失败。

## 6. `[001]` 专项结果

全部 512 张无噪声 `[001]` 研究图均完成三种检峰器调用，失败数为 0。
分组 recall 如下：

| 分组 | AutoDisk | py4DSTEM | DoG-RGM |
|---|---:|---:|---:|
| 精确 `[001]` | 1.0000 | 1.0000 | 0.8571 |
| 近 `[001]` | 0.8125 | 0.8055 | 0.7346 |
| 过渡区 3–6° | 0.4460 | 0.4335 | 0.4099 |
| `[100]` 对照 | 0.9996 | 0.9981 | 0.9376 |
| `[110]` 对照 | 0.9989 | 0.9981 | 0.9383 |

当前证据说明，图像检峰层的困难并不集中在精确 `[001]`，而集中在
3–6° 过渡区。后续 ACOM 已证明：直接物理峰输入也出现约 72° 的系统性
异常，因此根因不在二维图像渲染或圆盘检测层。

## 7. ACOM 结果

全部 2048 个 headline 样本已分别完成四条 ACOM 路径：

| 输入 | Acc@2° | P95 |
|---|---:|---:|
| 直接 First-Born 物理峰 | 78.86% | 9.167° |
| Clean-E → AutoDisk | 80.96% | 7.586° |
| Clean-E → `find_Bragg_disks` | 80.91% | 7.586° |
| Clean-E → DoG-RGM | 80.81% | 7.662° |

独立 `[001]` 512 样本的四条路径也全部运行，但中位误差均约 71.65–71.72°，
确认该异常不是图像找盘造成的。

Clean-C 目前使用固定 8 样本、repeat 0 完成九档电子剂量和四档 EMPAD-G2
读出噪声，共 39 条 ACOM。100 e⁻ 下 AutoDisk、py4DSTEM 分别有 2、1 个
样本因少于 3 峰而被明确记录为无法索引；其余调用均正常。剂量从 100
增加到 3000 e⁻ 时 Acc@2° 总体提高，随后受 8 样本离散性影响而波动。
固定 `10⁴ e⁻` 时，64 帧读出噪声令三种方法的 P95 分别升至
64.79°、71.23°、85.83°，说明噪声假阳性会触发严重错误分支。

完整结果与方法解释见 `reports/v5/V5_ACOM_RESULTS.md`。

## 8. 可复现性与程序状态

- 服务器 Conda 环境：`or4d-clean`；
- CPU 线程上限：8，低于单卡任务允许的 16；
- 基础配置下服务器单元测试：29/29 通过；
- 最困难复现检查：
  `100 e⁻ + EMPAD-G2 64 frames + repeat 0`；
- AutoDisk、py4DSTEM 和 DoG-RGM 重复运行后，样本 ID、峰 offsets、
  `qx/qy/intensity` 及全部逐峰诊断数组逐位一致；
- 三个方法的最大数值差均为 0；
- 所有正式检峰报告中的 `num_failures` 均为 0。

旧采样测试中有两个断言固定假设基础配置为 1024 个样本。因此运行单元测试
时应取消 `OR4D_CONFIG`；直接把 V5 overlay 注入旧测试会触发测试假设不匹配，
不是 V5 数据生成或检峰调用失败。

## 9. 已知警告与限制

1. pymatgen 持续报告 CIF 名义化学计量与解析占位率不完全一致：
   Ni 比例约 3.02775、Li 比例约 2.9778，其余主要元素约 3。该警告没有
   被隐藏，后续必须决定以 CIF 名义式还是解析结构为准。
2. 当前噪声层只包含 Poisson 计数和有文献依据的 EMPAD-G2 高斯读出噪声；
   没有加入背景、漂移、坏点、饱和、增益不均匀或椭圆畸变。
3. 读出噪声图不全部物化保存。正式保存基础 Poisson 图、噪声参数和确定性
   seed，检测时可逐像素精确重建，避免生成数百 GB 的冗余文件。
4. 2048 headline 与 `[001]` 已完成 Clean-E ACOM；Clean-C 剂量/噪声
   ACOM 当前为固定 8 样本诊断，不是 2048 headline 统计。
